# FitTrack

FitTrack is a Java project for recording members, workouts and fitness goals.

## Project plan

- Set up Eclipse and Maven with Java 25.
- Add member and workout classes, checked inputs and calculations.
- Add minutes and sessions goals using inheritance.
- Add memory storage, MySQL tables and JDBC storage.
- Connect the service rules to a Java HTTP server.
- Add the webpage, API tests and hosting settings.
- Finish with the complete beginner setup guide.

## Current contents

The project plan and Git ignore rules are included. Application code is not yet included.
